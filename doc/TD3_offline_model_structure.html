🔬 模块详解

逐一剖析各个子网络的结构、参数与数据流。

FeatureAttention — 特征注意力门控

通用模块，Actor 与 Critic 共享结构

设计动机

无人机状态向量中不同维度（如位置、速度、姿态）对决策的重要性不同且时变。 FeatureAttention 通过学习一个 Sigmoid 门控权重，让网络自适应地关注关键特征维度、抑制噪声维度。

前向传播

x (B,T,D) → Reshape (B·T, D) → Linear(D→64) → ReLU → Linear(64→D) → Sigmoid → Reshape (B,T,D) → x ⊙ gate (B,T,D)

关键参数

参数值说明
input_dimstate_dim = 3输入特征维度（与状态空间一致）
hidden_dimattn_hidden_dim = 64注意力隐藏层维度
激活函数ReLU → Sigmoid门控值 ∈ (0,1)，逐元素乘回原输入

ActorLSTM — 策略网络

输出连续动作向量

设计动机

降落是一个时序决策过程——历史状态蕴含了速度趋势、高度变化率等关键信息。 LSTM 使得策略能基于过去 8 步的状态序列做出当前决策，而非仅依赖单帧状态。

前向传播

s_seq (B,8,3) → FeatureAttention → Linear(3→256) → LayerNorm(256) → ReLU → Dropout(p=0.1) → LSTM(256→256, batch_first) → 取 x[:, -1, :] → Linear(256→3) → tanh × max_action → action (B,3) ∈ [-1,1]

关键参数

参数值说明
state_dim3观测空间维度
action_dim3动作空间维度
max_action1.0动作幅值上限（tanh 后缩放）
hidden_dim256全连接层 & LSTM 隐藏维度
attn_hidden_dim64FeatureAttention 内部隐藏维度
dropout_p0.1Dropout 概率（正则化）

CriticLSTM — 价值网络

评估状态-动作对的 Q 值

设计动机

Critic 需要同时考虑状态序列和动作序列来估计 Q 值。将状态-动作拼接后送入 LSTM， 让价值估计能利用完整的时序上下文。双 Critic (Q1, Q2) 取最小值缓解过估计偏差。

前向传播

s_seq (B,8,3) + a_seq (B,8,3) → FeatureAttention(s) → Concat → (B,8,6) → Linear(6→256) → LayerNorm(256) → ReLU + Dropout(0.1) → LSTM(256→256) → 取 x[:, -1, :] → Linear(256→1) → Q(s,a) (B,1)

关键参数

hidden_dim256全连接 & LSTM 隐藏维度
attn_hidden_dim64FeatureAttention 内部隐藏维度
dropout_p0.1Dropout 概率
输出标量 Q 值Linear(256→1)

TD3-BC 损失函数

# Critic Loss (MSE, 双 Q)
y = r + (1 - d) · γ · min(Q1_target(s', a2_seq), Q2_target(s', a2_seq))
L_critic = MSE(Q1(s,a), y) + MSE(Q2(s,a), y)

# Actor Loss (TD3 + BC 正则)
L_td3  = -Q1(s, a_mix).mean()          # 最大化 Q 值
L_bc   = MSE(π_last, a_last)  [× is_expert 掩码]
λ      = α / |Q|̄                       # 自适应 BC 权重
L_actor = L_td3 + (bc_weight · λ) · L_bc

Mixed-History 机制

Actor 只输出最后一步动作 π_last。构造 混合序列 送入 Critic 评估： 前 T−1 步使用数据集真实动作，最后一步替换为 Actor 输出。 这使 Critic 能在真实历史上下文中评估当前策略的价值。

⚙️ 训练流程

从数据加载到权重保存的完整 pipeline。

1

加载离线数据

支持 JSON/JSONL 多格式解析，自动按 done 标志切分 episode，支持滑窗序列构建

2

计算归一化统计量

遍历所有 observation 计算 mean/std，保存为 state_mean.npy / state_std.npy

3

构建序列回放池

对每个 episode 以 seq_len=8 滑窗构建序列样本，跳过跨 done 边界的窗口，写入 SequenceReplayBuffer

4

离线训练循环 (100K steps)

每步随机采样 batch → Critic 更新 → 延迟 Actor 更新 (TD3-BC) → 软更新目标网络

5

定期保存 & TensorBoard 日志

每 10,000 步保存 checkpoint (actor/critic1/critic2)，每 61 步记录损失曲线
